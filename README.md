# چیره فرآور گستر | نمونه‌کار وب‌سایت صنعتی

وب‌سایت فارسی و راست‌چین برای معرفی تجهیزات آزمایشگاهی فرآوری مواد معدنی. این پروژه نمونه‌کار طراحی وب است و جایگزین وب‌سایت رسمی شرکت نیست.

## بخش‌های سایت

- صفحهٔ اصلی، دربارهٔ شرکت، خدمات، تماس، پرسش‌های متداول و حریم خصوصی
- کاتالوگ محصولات با صفحهٔ اختصاصی دستگاه‌ها
- دانشنامه و مقاله‌های کاربردی
- طراحی واکنش‌گرا برای دسکتاپ و موبایل
- فرم تماس و درخواست مشاوره که پیام را در برنامهٔ ایمیل کاربر آماده می‌کند؛ این نمونه به سامانهٔ فروش یا پایگاه داده وصل نیست

## اجرای محلی

Python 3 کافی است و بستهٔ اضافی لازم نیست:

```sh
python -m http.server 8000 --directory dist
```

سپس `http://localhost:8000/` را باز کنید.

## ساختار پروژه

- `dist/`: فایل‌های آمادهٔ میزبانی و همهٔ صفحه‌های سایت
- `dist/assets/`: سبک‌ها، اسکریپت‌ها، فونت و تصاویر
- `build.py`: ساخت نسخهٔ ایستای سایت از داده‌های محتوایی
- `product_*.json` و فایل‌های JSON ریشه: محتوای دستگاه‌ها و کاتالوگ
- `.github/workflows/deploy-pages.yml`: روند آماده‌سازی و انتشار در GitHub Pages

## انتشار در GitHub Pages

در تنظیمات مخزن، بخش **Pages** را روی **GitHub Actions** بگذارید و از زبانهٔ **Actions** روند **Deploy Chireh website to GitHub Pages** را اجرا کنید. روند انتشار مسیرهای ریشه را برای نشانی پروژه در GitHub Pages تنظیم می‌کند.

## توضیح تصاویر

مشخصات دستگاه‌ها و بعضی تصاویر محصول بر اساس محتوای عمومی چیره فرآور گستر تهیه شده‌اند. تصاویر محیطی برای نمایش بصری نمونه‌کار استفاده شده‌اند. پیش از استفادهٔ تجاری مستقل، مجوز تصاویر را بررسی کنید.
